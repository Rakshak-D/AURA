# A0 Dependency Decisions

Reviewed 2026-11-15 before changing dependency manifests. Proposed pins are exact stable releases and stay within the existing FastAPI/Pydantic 2, SQLAlchemy 2.0, APScheduler 3, PyJWT 2, and pwdlib families. Python 3.11 and 3.12 are the target interpreters. Initial clean Windows installs succeeded; full compatibility results are recorded in `TEST_RESULTS.md`.

## Compatibility decision gates

- Apply these pins only after this table is recorded.
- The final proposal may change only if installation or an AURA regression demonstrates a compatibility issue; update this table first.
- No optional LLM, GPU, ChromaDB, OCR, or model-download dependency is added to the core install.
- Pass/fail compatibility evidence for Python 3.11, Python 3.12, and Windows must come from actual executions, not package metadata alone.
